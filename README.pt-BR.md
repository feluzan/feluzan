## Projeto em destaque

### [`raava-framework`](https://github.com/feluzan/raava-framework)

Um framework opinativo em Java para desenvolvimento de APIs REST corporativas, criado para reduzir trabalho repetitivo de backend em fluxos de CRUD, filtros, autenticação, auditoria e contratos web consistentes.

Ele é a expressão mais clara de como gosto de construir software: abstrações pragmáticas, padrões que favorecem manutenção e infraestrutura que ajuda sistemas de negócio a evoluírem sem se tornarem mais difíceis de operar.
